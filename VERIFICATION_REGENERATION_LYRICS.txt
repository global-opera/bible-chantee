================================================================================
                           SCRIPT DE RÉGÉNÉRATION
================================================================================

Fichier: regenerate_lyrics_data.py

Utilisation:
  python regenerate_lyrics_data.py

Le script:
  1. Lit chaque fichier lyrics/{LANG}.json
  2. Trie les livres et chapitres par numéro
  3. Échappe les caractères spéciaux JavaScript
  4. Génère les fichiers lyrics-data*.js avec template literals
  5. Affiche un rapport de progression

Peut être réexécuté à tout moment pour mettre à jour les fichiers.
