❓ Questions fréquentes

C'est vraiment 100 chapitres gratuits ?

Oui ! Vous choisissez 100 chapitres dans la langue de votre choix. Une fois débloqués, ils sont à vous à vie avec réécoute illimitée.

Puis-je débloquer dans plusieurs langues ?

Oui ! Chaque langue a ses propres 100 crédits gratuits. Vous pouvez écouter 100 chapitres en français + 100 en portugais + 100 en anglais.

Comment fonctionne le paiement ?

Paiement sécurisé via PayPal. Après paiement, vous recevez un code par email qui débloque tous les 1189 chapitres dans la langue choisie.

Puis-je télécharger les MP3 ?

Les chapitres sont disponibles en streaming. Pour l'instant, pas de téléchargement disponible.

Est-ce que mes chapitres débloqués sont sauvegardés ?

Oui, dans votre navigateur (localStorage). Si vous effacez vos données, utilisez votre code de déblocage pour restaurer l'accès.
