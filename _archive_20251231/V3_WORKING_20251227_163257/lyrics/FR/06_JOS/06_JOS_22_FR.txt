[TITLE]
Josué 22 - Témoin de notre Unité

[LYRICS]
[Verse 1]  
Josué a convoqué son peuple,  
Les Rubénites, Gadites, avec cœur,  
Vous avez suivi la voix du Seigneur,  
Obéissant, fidèles, porteurs de l’honneur.  
Maintenant partez, vos frères reposent,  
Retournez dans vos tentes, sous le ciel radieux,  
Aimez l’Éternel, marchez dans ses voies,  
Servez-le de tout votre cœur, en toutes choses.

[Chorus]  
Éternel, notre Dieu, nous te louons,  
Pour les promesses, pour ta direction,  
Dans l’unité, nous marchons, main dans la main,  
Témoin pour toujours, notre amour est certain.

[Verse 2]  
Ils bâtirent un autel, un symbole fort,  
Pour que jamais ils ne soient séparés,  
Un témoignage d’unité, un accord,  
Pour que leurs enfants ne soient pas égarés.  
Mais la rumeur a couru, la crainte s’est levée,  
Le peuple s’est rassemblé, prêt à s’affronter,  
Phinées envoyé, pour comprendre l’affaire,  
Il cherche la vérité, pour éviter la guerre.

[Chorus]  
Éternel, notre Dieu, nous te louons,  
Pour les promesses, pour ta direction,  
Dans l’unité, nous marchons, main dans la main,  
Témoin pour toujours, notre amour est certain.

[Bridge]  
Si nous bâtissons, c’est pour te célébrer,  
Pas pour nous détourner, mais pour te glorifier,  
Loin de nous l’idée de te révolter,  
Nous voulons être unis, dans l’amour partagé.

[Verse 3]  
Phinées a compris, il a reconnu,  
L’Éternel est avec nous, sa grâce est reçue,  
Le peuple a béni, la paix a régné,  
L’autel est un témoin, de notre fidélité.  
Dans la joie, ils retournent, chacun à son foyer,  
L’Éternel est notre Dieu, pour l’éternité,  
Nous marcherons ensemble, main dans la main,  
Pour servir notre Seigneur, sur ce chemin.

[Chorus]  
Éternel, notre Dieu, nous te louons,  
Pour les promesses, pour ta direction,  
Dans l’unité, nous marchons, main dans la main,  
Témoin pour toujours, notre amour est certain.
