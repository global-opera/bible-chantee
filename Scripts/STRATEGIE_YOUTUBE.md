## 📅 4. CALENDRIER DE PUBLICATION

### 4.1 Phase de lancement (Mois 1-2)

**Semaine 1-4**: Publications intensives
- **Lundi-Vendredi**: 5 vidéos/jour (chapitres prioritaires)
- **Week-end**: 2 vidéos/jour

**Total**: 156 vidéos en 4 semaines

**Ordre de priorité**:
1. **Top 50** chapitres les plus connus (voir section 2.1 playlists spéciales)
2. **Psaumes 1-50** (contenu le plus recherché)
3. **Évangiles** (Matthieu → Jean complets)
4. **Genèse + Exode** (fondations AT)

### 4.2 Phase de croissance (Mois 3-6)

**Rythme régulier**:
- **2-3 vidéos/jour** (14-21/semaine)
- **Complétion par livre**: Finir chaque livre entamé avant de passer au suivant

**Total**: 250-350 vidéos en 4 mois

### 4.3 Phase de complétion (Mois 7-12)

**Rythme stable**:
- **1-2 vidéos/jour** (7-14/semaine)
- Focus sur livres restants (prophètes mineurs, épîtres courtes)

**Total**: Tous les chapitres en 12 mois maximum

### 4.4 Horaires de publication optimaux

**Meilleurs créneaux** (fuseau France):
- **6h00**: Prière du matin
- **12h00**: Pause déjeuner
- **20h00**: Prière du soir
- **22h00**: Méditation nocturne

**Jours prioritaires**: Dimanche (pic d'engagement)

## 🤖 5. WORKFLOW D'AUTOMATISATION

### 5.1 Script Python de upload YouTube

**Utiliser**: YouTube Data API v3 avec `google-api-python-client`

**Fonctionnalités requises**:
```python
def upload_chapter_to_youtube(book_code, chapter_num):
    """
    Upload automatique d'un chapitre sur YouTube

    - Lit le fichier MP4 depuis Videos/FR/[book]/
    - Génère titre/description/tags depuis template
    - Upload avec thumbnail automatique
    - Ajoute à la playlist correspondante
    - Sauvegarde l'URL YouTube dans video_metadata.json
    """
```

**Configuration**:
- Authentification OAuth2
- Rate limiting: Max 6 uploads/jour (quota YouTube gratuit)
- Retry logic pour erreurs réseau
- Log complet des uploads

### 5.2 Générateur de thumbnails

**Script**: `generate_thumbnails.py`

**Utiliser**: Pillow (PIL) pour composition d'images

**Pipeline**:
1. Charger template de fond par livre
2. Ajouter texte titre (police Roboto Bold 120pt)
3. Ajouter sous-titre (Roboto Regular 60pt)
4. Ajouter logo "Bible Chantée"
5. Sauvegarder dans `Thumbnails/FR/[book]/[chapter].jpg`

### 5.3 Fichier de tracking

**Créer**: `youtube_uploads.json`

```json
{
  "01_GEN": {
    "1": {
      "uploaded": true,

      "upload_date": "2025-12-07",
      "views": 1250,
      "likes": 89,
      "playlist_id": "PLxxx..."
    }
  }
}
```

### 5.4 Launcher batch

**Créer**: `LANCER_UPLOAD_YOUTUBE.bat`

```batch

echo ========================================================================
```
